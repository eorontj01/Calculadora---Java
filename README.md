# 🧮 Calculadora Java

Minha primeira calculadora desenvolvida em Java utilizando o NetBeans.

## 📌 Sobre o projeto

Projeto desenvolvido como parte dos meus estudos de Java e lógica de programação.

A calculadora possui operações matemáticas básicas e algumas operações adicionais.

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- X Multiplicação
- ➗ Divisão
- ^ Potenciação
- % Porcentagem
- √ Raiz quadrada
- Validação de divisão por zero
- Validação de campos vazios

## 🛠️ Tecnologias utilizadas

- Java
- Java Swing
- NetBeans

## 🎯 Objetivo

Praticar conceitos fundamentais de programação em Java, incluindo:

- Estruturas condicionais
- Métodos
- Manipulação de componentes gráficos
- Conversão de valores
- Tratamento de exceções
- Lógica de programação
